# Jenkins CI/CD Hello World Project 🚀

This project demonstrates a basic CI/CD pipeline using Jenkins and GitHub.

## Technologies Used
- HTML
- CSS
- JavaScript
- Git
- GitHub
- Jenkins

## Features
- Automated deployment using Jenkins
- GitHub integration
- Continuous Integration and Deployment (CI/CD)
- Simple responsive web page

## CI/CD Workflow
1. Code pushed to GitHub
2. Jenkins pulls latest code
3. Jenkins deploys website automatically
4. Website updated in deployment folder
